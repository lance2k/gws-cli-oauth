Privacy policy

gws-cli is used only by its owner, with the owner's own Google accounts.

What it accesses. With the owner's consent it reads data from those Google accounts, such as Gmail messages, through Google's APIs.

Where the data goes. The data is read on the owner's own computer for the owner's own use. It is not sold, shared with third parties, or used for advertising. No server run by this project receives or stores it.

Sign-in tokens. Google sign-in tokens are stored encrypted on the owner's computer and can be revoked at any time at myaccount.google.com/permissions.

Contact. Open an issue on this site's GitHub repository.
